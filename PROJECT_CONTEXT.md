# NGConsole Project Context

## Purpose
NGConsole is a native macOS network engineering workspace.

## Product Goal
Provide one application for:
- Terminal (SSH, Telnet, Serial, Local Shell)
- File Transfer (SFTP/FTP/TFTP Client & Server)
- Workspace management
- Python automation
- AI assistant (optional)

## Target Users
Network engineers, system engineers, operations teams.

## Technology
Swift, SwiftUI, Swift Concurrency, Apple Keychain.

## Core Principles
- Console First
- Workspace Driven
- Plugin Architecture
- Offline First
- Native macOS
- Security First

## Development Rule
Architecture decisions originate from documentation before implementation.
